# LiroycEffects — גרסה עברית

תוכנת גרפיקת תנועה ואפקטים חזותיים, מבוססת על EffectCraft (קוד פתוח, MIT / Apache-2.0).
הגרסה הזאת כוללת: ממשק בעברית כברירת מחדל, ערכת צבעים סגול/תכלת/כחול/ורוד, הלוגו של LiroycEffects,
ופונטים Heebo / Rubik / Assistant.

## איך מקבלים קובץ הרצה (הדרך הקלה — בלי להתקין כלום)
1. צור חשבון ב־GitHub (חינם) וצור מאגר (repository) חדש.
2. העלה אליו את כל תוכן התיקייה הזאת (Upload files, או `git push`).
3. היכנס ללשונית **Actions** ▸ **בניית LiroycEffects** ▸ **Run workflow**.
4. אחרי כ־30–60 דקות, בתחתית הריצה, באזור **Artifacts**, הורד את הגרסה למערכת שלך
   (`LiroycEffects-windows.zip` / `-linux.zip` / `-macos.zip`), חלץ והפעל את `effectcraft.exe`.
   ליד קובץ ההרצה יש תיקיית `fonts` — אל תמחק אותה, היא מכילה את הפונטים.

## בנייה מקומית
```
cargo build --release -p effectcraft
```
(דורש Rust 1.95 ומעלה.) העתק את הקובץ מ־`target/release/` ואת התיקייה `fonts` (פונטים Heebo/Rubik/Assistant)
לאותה תיקייה.

## שפה
ברירת המחדל היא עברית. אפשר להחליף בהגדרות ▸ כללי ▸ שפה.

## מה לדעת
* הכתיבה מימין לשמאל מתבצעת בקירוב: egui אינה תומכת ב־RTL מלא, ולכן סדר המילים במשפטים הפוך
  מראש (ראה `crates/ui-egui/src/i18n/he.rs`, קבוע `VISUAL_ORDER`). פריסת הלוחות עצמם אינה מתהפכת.
* שמות אפקטים (306 אפקטים), שמות מאפיינים בתוך האפקטים והודעות שגיאה פנימיות נשארו באנגלית.
* שמות קבצים וקיצורי מקלדת נשארו כמו במקור, כדי לשמור על תאימות לפרויקטים קיימים.
